# ☕ Coffee Sales Dashboard – Excel Data Analysis

## 📌 Project Overview
This project analyzes coffee sales data to identify sales trends, customer preferences, and product performance using Microsoft Excel. An interactive dashboard was developed to present key business insights and support data-driven decision-making.

## 🎯 Business Objectives
- Analyze sales performance over time.
- Identify top-selling coffee products.
- Track revenue trends and customer purchasing patterns.
- Build an interactive dashboard using charts, timelines, and slicers.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers & Timeline
- Data Cleaning and Visualization

## 📊 Key Features
- Interactive sales dashboard
- Monthly sales trend analysis
- Product performance analysis
- Dynamic filtering using slicers
- Time-based analysis using a timeline

## 💡 Key Insights
- Identified sales trends across different time periods.
- Compared product performance to understand customer preferences.
- Presented sales data through interactive visualizations.
